# EXCEL-ASSIGNMENT-2
## 📖 Overview
This project demonstrates data cleaning, transformation, and formatting techniques using Microsoft Excel. The assignment focuses on preparing a raw product dataset for analysis by handling missing values, correcting inconsistencies, removing duplicates, transforming data, and applying formatting rules.

---

## 🎯 Objectives
- Handle missing values in the dataset.
- Correct inconsistent text formatting and spelling mistakes.
- Remove duplicate records.
- Split and merge columns using Excel tools and formulas.
- Apply number and date formatting.
- Use conditional formatting to improve data visualization.

---

## 📂 Dataset Information
**Dataset:** Product Dataset

### Attributes
- Product ID
- Product Name
- Brand Name
- Price
- Quantity
- Category

---

## 🛠 Tasks Performed

### 1. Missing Value Handling
- Identified missing values in the **Price** column.
- Replaced missing prices using the average price.
- Filled missing categories based on the corresponding product type.

### 2. Data Standardization
- Corrected inconsistent text formatting in the **Product Name** column.
- Fixed spelling mistakes in the **Category** column using Find & Replace.

### 3. Duplicate Removal
- Identified duplicate records.
- Removed duplicate rows using Excel's **Remove Duplicates** feature.

### 4. Data Transformation
- Split the **Product ID** into:
  - Manufacturing Date
  - Country Code
- Merged **Brand Name** and **Product Name** into a new column called **Product Brand**.

### 5. Number Formatting
- Formatted the **Price** column as Currency.
- Formatted the **Manufacturing Date** column in **DD-MM-YYYY** format.

### 6. Conditional Formatting
- Applied **Data Bars** to the Price column.
- Highlighted cells containing **Electronics** in the Category column using Conditional Formatting.
